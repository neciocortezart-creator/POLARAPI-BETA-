# Polar

Polar es una calculadora de carbohidratos e insulina. Es una aplicación web instalable (PWA) para el cálculo y el registro del día a día.

El sitio público permite usar la aplicación. El código, el diseño, el nombre «Polar» y los recursos pertenecen a su autor.
